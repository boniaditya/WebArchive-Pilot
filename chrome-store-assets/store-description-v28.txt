**Store Description**

📦 **WebArchive Pilot** helps you save webpages as `.webarchive` files, bundle multiple saved pages into a tabbed archive, and reopen everything directly inside Chrome.

Whether you are saving research, product pages, receipts, dashboards, support articles, documentation, learning material, reports, or important references, WebArchive Pilot gives you a practical way to keep a portable copy of a page after it has fully loaded in your browser.

Instead of relying on bookmarks alone, broken offline saves, or pages that may change later, WebArchive Pilot helps you preserve what you actually saw in the browser.

✨ **What makes WebArchive Pilot useful?**

WebArchive Pilot is designed for people who want a clean, lightweight archive workflow inside Chrome.

With WebArchive Pilot, you can:

🔹 Save the current page as a `.webarchive` file  
🔹 Save all open tabs in the current window into one bundled archive  
🔹 Save only the tabs on the left of the active tab into one bundled archive  
🔹 Save only the tabs on the right of the active tab into one bundled archive  
🔹 Save pages from the right-click context menu  
🔹 Open `.webarchive` files directly inside Chrome  
🔹 Open bundled archive files directly inside Chrome  
🔹 Reopen downloaded archives from a built-in archive library  
🔹 Build one bundled archive from multiple previously downloaded `.webarchive` files  
🔹 Browse bundled pages in a tabbed sidebar for quick switching  
🔹 View archives created by Safari as well as archives created by this extension

🧭 **Built for real everyday use**

WebArchive Pilot is helpful when you want to:

📚 Save research material for later  
🛍 Archive product pages before prices, stock, or details change  
🧾 Keep copies of receipts, invoices, and order confirmations  
📰 Save articles, posts, and public pages that might be edited or removed  
💼 Preserve business dashboards, reports, and internal references after they load  
🧠 Collect learning resources and documentation in one place  
🗂 Group many related pages into one bundled archive for easier organization

🛠 **How it works**

WebArchive Pilot uses Chrome’s built-in page capture capabilities to preserve the fully loaded page and package it as a `.webarchive` file. It also includes a built-in viewer that can decode and render saved archives directly in a Chrome tab, so you do not need Safari just to reopen them.

For larger workflows, WebArchive Pilot also supports bundled tab archives, allowing multiple saved pages to be grouped into one portable archive file and previewed through a vertical tabbed interface inside the viewer. This is especially useful when you want to keep a full set of related pages together instead of managing many separate files one by one.

🖥 **Built-in archive library**

📁 Jump to files from your archive list for quick access

❓ **FAQ**

❔ **What can I save with WebArchive Pilot?**  
You can save many regular webpages, including articles, product pages, dashboards, documentation pages, and other content that has fully loaded in Chrome.

❔ **Can I open `.webarchive` files in Chrome?**  
Yes. WebArchive Pilot includes a built-in viewer that lets you open `.webarchive` files directly inside Chrome.

❔ **Can I save multiple tabs together?**  
Yes. You can save all tabs, the tabs on the left, or the tabs on the right into a bundled archive for easier organization.

❔ **Can I reopen bundled archives later?**  
Yes. Bundled archives can be opened in WebArchive Pilot’s viewer, where archived pages can be switched through a tabbed sidebar.

❔ **Does this work with Safari `.webarchive` files?**  
Yes. WebArchive Pilot is designed to view Safari-created `.webarchive` files as well as files created by the extension.

❔ **Why would I use this instead of bookmarks?**  
Bookmarks only point to the live page. WebArchive Pilot helps you keep a saved copy of what you saw at the time, which is useful when content changes later.

❔ **Does it work for pages that require login?**  
It can help preserve pages after they have loaded in your browser, which can be useful for authenticated or dynamically rendered content. However, replay behavior may vary depending on how the site works.

❔ **Will every website replay perfectly later?**  
Not always. Some highly interactive websites or pages that depend on live server responses may not replay exactly the same when reopened.

❔ **Can Chrome internal pages be archived?**  
No. Browser-internal pages such as `chrome://` pages cannot be archived by Chrome extensions.

❔ **Do I need Safari to open these files?**  
No. That is one of the main benefits of WebArchive Pilot. You can reopen supported archive files directly inside Chrome.

📝 **Important notes**

• Some websites may not replay exactly the same if they depend on live server data, advanced scripts, or real-time interactions.  
• Browser-internal pages such as `chrome://` pages cannot be archived.  
• Bundled archives are designed for use with WebArchive Pilot’s built-in viewer.  
• Results depend on how the webpage loaded and what resources were available at capture time.

❓ **Additional FAQ**

❔ **What is a `.zarc` file?**  
A `.zarc` file is a WebArchive Pilot bundle that stores multiple complete `.webarchive` files together. Open it in WebArchive Pilot to browse the included pages through a vertical tab interface.

❔ **Does a `.zarc` bundle contain the actual webpages?**  
Yes. The bundle stores embedded `.webarchive` files rather than references to files on your computer.

❔ **Can I export every archive format?**  
Export options are available for compatible `.webarchive` files that WebArchive Pilot can decode. `.zarc` bundles can be opened to access their contained web archives.

❔ **Why might an archive fail to open?**  
The source archive may be incomplete, damaged, unavailable on disk, unsupported, or contain resources that cannot be replayed offline. WebArchive Pilot shows an error instead of loading indefinitely when file access fails.

❔ **Why might a saved webpage look different later?**  
Some websites rely on live server data, login sessions, scripts, video players, or interactive services that cannot be fully reproduced offline. Archive results depend on what Chrome captured when the page was saved.

❔ **Can I use the extension with Safari archives?**  
Yes. WebArchive Pilot is designed to open many Safari-created `.webarchive` files as well as archives created by the extension itself.
